# 🚀 راهنمای راه‌اندازی نوتیفیکیشن آنی ابری DevScout (دقیقاً مثل تلگرام)

این راهنما توضیح می‌دهد که چطور سیستم اطلاع‌رسانی آنی DevScout را با استفاده از **اسکرپر ابری (Cloud Scraper)** و **Firebase Cloud Messaging (FCM)** راه‌اندازی کنید تا **حتی زمانی که اپلیکیشن DevScout کاملاً بسته (Force-close) است و بدون مصرف باتری**، به محض انتشار آگهی جدید در پونیشا، کارلنسر، جابینجا یا جاب‌ویژن، نوتیفیکیشن فوری با صدا و ویبره روی گوشی شما ظاهر شود.

---

## 💡 تلگرام چطور بدون باز بودن برنامه نوتیفیکیشن می‌فرستد؟

در سیستم‌عامل اندروید، وقتی کاربری برنامه‌ای را می‌بندد (Swipe away)، سیستم‌عامل برای کاهش مصرف باتری، پردازش‌های داخلی برنامه را متوقف می‌کند. 
برنامه‌هایی مانند **تلگرام، واتساپ و جیمیل** برای ارسال نوتیفیکیشن روی گوشی به برنامه باز وابسته نیستند؛ بلکه **یک سرور در اینترنت** پیام را از طریق پروتکل رسمی گوگل (**Google Play Services / FCM**) به گوشی ارسال می‌کند. گوشی شما حتی در حالت قفل یا بسته بودن برنامه، این پیام را مستقیماً از سرورهای گوگل دریافت کرده و فوراً نوار اعلان را با صدا و ویبره بالا می‌آورد.

اکنون ما دقیقاً همین معماری را در پوشه `backend_notifier/` برای DevScout پیاده‌سازی کرده‌ایم!

## 🛠️ روش اول: اجرای کاملاً رایگان با GitHub Actions (بدون نیاز به سرور و هزینه)

شما می‌توانید با استفاده از بخش **GitHub Actions**، این ربات اسکرپر را هر ۵ الی ۱۰ دقیقه به صورت ۲۴ ساعته و کاملاً رایگان روی سرورهای ابری گیت‌هاب اجرا کنید!

### مرحله ۱: دریافت کلید سرویس فایربیس (Service Account Key)
1. وارد [کنسول فایربیس](https://console.firebase.google.com/) شوید و پروژه خود را انتخاب کنید.
2. روی آیکون چرخ‌دنده ⚙️ در کنار **Project Overview** کلیک کرده و وارد **Project settings** شوید.
3. تب **Service accounts** را باز کنید.
4. دکمه **Generate new private key** را بزنید و سپس **Generate key** را تایید کنید.
5. یک فایل با پسوند `.json` دانلود می‌شود. محتویات متنی این فایل را باز کرده و تمام متن آن را کپی کنید.

### مرحله ۲: ثبت کلید در گیت‌هاب
1. پروژه خود را روی گیت‌هاب (مخزن شخصی Private یا Public) آپلود یا Push کنید.
2. در گیت‌هاب به مسیر زیر بروید:
   `Settings` ➔ `Secrets and variables` ➔ `Actions`
3. دکمه سبز رنگ **New repository secret** را بزنید.
4. در کادر Name بنویسید:
   ```text
   FIREBASE_SERVICE_ACCOUNT_KEY
   ```
5. در کادر Secret، کل متنی که از فایل `.json` فایربیس کپی کرده بودید را پیست کنید و دکمه **Add secret** را بزنید.

### مرحله ۳: لذت بردن از دریافت خودکار!
* فایل ورک‌فلو `.github/workflows/cloud_scraper_cron.yml` به صورت خودکار هر ۱۰ دقیقه اجرا می‌شود.
* ۴ سایت را اسکرپ می‌کند و به محض مشاهده هر آگهی استخدامی یا فریلنسری جدید، مستقیماً نوتیفیکیشن با اولویت بالا به گوشی شما می‌فرستد!
* همچنین می‌توانید در تب **Actions** گیت‌هاب، روی **DevScout 24/7 Cloud Scraper** کلیک کرده و با زدن دکمه **Run workflow**، آن را در همان لحظه به صورت دستی اجرا کنید.

## 🖥️ روش دوم: اجرا روی هاست، سرور مجازی (VPS) یا سیستم شخصی

اگر سرور لینوکس، هاست نودجی‌اس یا کامپیوتر شخصی دارید، می‌توانید به سادگی این اسکرپر را همیشه فعال نگه دارید:

### ۱. قرار دادن کلید فایربیس
فایل دانلودی از فایربیس را با نام `serviceAccountKey.json` در پوشه `backend_notifier/` قرار دهید.

### ۲. نصب پکیج‌ها و اجرای دستی
```bash
cd backend_notifier
npm install
node index.js
```

### ۳. تست فوری ارسال اعلان به گوشی بسته
برای اینکه مطمئن شوید گوشی شما نوتیفیکیشن فایربیس را دریافت می‌کند:
```bash
node test_push.js
```
گوشی شما حتی اگر قفل یا خاموش باشد، ظرف چند ثانیه با صدای اعلان روشن می‌شود و با ضربه روی آن، مستقیم به برنامه هدایت می‌شوید!

### ۴. اجرای دائمی با PM2 (پیشنهادی برای سرور)
برای اینکه اسکریپت هر ۵ دقیقه یک بار در سرور اجرا شود:
```bash
npm install -g pm2
pm2 start index.js --name "devscout-notifier" --cron "*/5 * * * *"
pm2 save
```

## 🎯 نتیجه‌گیری

با فعال‌سازی این سیستم ابری:
1. **۱۰۰٪ تضمینی**: حتی اگر گوشی را ری‌استارت کنید، صفحه خاموش باشد، یا اپ کاملاً بسته (Force-stop) باشد، نوتیفیکیشن در همان ثانیه انتشار آگهی می‌رسد.
2. **صفر درصد مصرف باتری**: هیچ پردازش اضافه‌ای روی گوشی شما انجام نمی‌شود و تمام کار سنگین اسکرپینگ در کلود انجام می‌شود.
3. **دیپ‌لینک مستقیم**: با ضربه روی هر نوتیفیکیشن، مستقیماً صفحه همان آگهی در DevScout باز می‌شود.
